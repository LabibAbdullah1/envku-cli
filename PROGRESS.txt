================================================================================
[4] CARA MENJALANKAN & MENGUJI
================================================================================
A. Di Linux Desktop / Laptop Pribadi:
   1. Install:
      curl -fsSL https://raw.githubusercontent.com/LabibAbdullah1/envku-cli/main/scripts/install.sh | sudo bash -s -- --local
   2. Jalankan TUI:
      sudo envku
   3. Pasang phpMyAdmin dan buka di browser:
      Pilih menu [6] -> [1] Buka phpMyAdmin di Browser (atau 'envku pma open')

B. Di Server VPS / Cloud:
   1. Install:
      curl -fsSL https://raw.githubusercontent.com/LabibAbdullah1/envku-cli/main/scripts/install.sh | sudo bash -s -- --production
   2. Pasang firewall dan amankan server:
      sudo envku mode production
