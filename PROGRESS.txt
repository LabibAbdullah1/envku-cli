[3] CARA MENJALANKAN & MENGUJI
================================================================================

A. DI WINDOWS (Git Bash / WSL / CMD):
   1. Menjalankan TUI lokal:
      go run cmd/envku/main.go

   2. Cross-compile binary untuk Linux VPS dari Git Bash:
      GOOS=linux GOARCH=amd64 go build -ldflags="-s -w" -o envku cmd/envku/main.go

   3. Cross-compile binary untuk Linux VPS dari PowerShell:
      $env:GOOS="linux"; $env:GOARCH="amd64"; go build -ldflags="-s -w" -o envku cmd/envku/main.go

B. DI SERVER LINUX / VPS / WSL 2:
   1. Install langsung via bootstrap script:
      sudo bash scripts/install.sh

   2. Atau jalankan binary langsung:
      sudo ./envku
